Self-hosted signature font assets

The style 2 and 3 binaries come unmodified from the official Google Fonts repository.
Each accompanying *-OFL.txt contains its copyright notice and SIL Open Font
License 1.1. Keep the license files with redistributed copies.

For styles 2 and 3, the same font bytes are served from client/public/legal/fonts
and embedded by the backend from server/private/legal/fonts so browser and PDF
signatures use the same glyphs. Do not replace a font behind an existing signature
style identifier.

Style 1: Original signature appearance
Browser: Segoe Print, Bradley Hand, cursive; italic, using available system fonts.
PDF: Existing NotoSans-Regular.ttf, preserving the original typed-signature PDF.
No additional style 1 font asset is bundled. No Microsoft font is redistributed.

The style 2 and 3 official metadata files include the Vietnamese subset. Local checks
confirmed all U+1EA0-U+1EF9 precomposed Vietnamese characters, the Vietnamese
alphabet extensions, and combining marks used by decomposed Vietnamese names.
Dancing Script and Great Vibes support the installed pdf-lib/fontkit subset
embedding path and were visually checked with Vietnamese names.
